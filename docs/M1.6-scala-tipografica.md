## 1. La scala bersaglio

Sette gradini diventano **sette**, ma non gli stessi: spariscono `md` e `title`, entrano
`2xl` e `3xl`. I valori normali sono «+1» esatto su ogni gradino del v1; i touch sono
`arrotonda(px × 1.08)`, che è la regola già dichiarata dal tema.

| gradino | oggi | **nuovo** | touch | chi lo usa |
|---|---|---|---|---|
| `xs` | 11 | **12** | 13 | 22 usi — micro-etichette, etichette di gruppo sidebar |
| `sm` | 12 | **13** | 14 | **72 usi** — voci sidebar, breadcrumb, menu, e da ora i bottoni |
| ~~`md`~~ | 13 | **eliminato** | — | 2 usi, `button` e `button-group` → passano a `sm` |
| `base` | 14 | **15** | 16 | 9 usi — corpo, input |
| `lg` | 15 | **16** | 17 | 0 usi nei componenti |
| `xl` | 18 | **19** | 21 | 0 usi nei componenti |
| ~~`title`~~ | 26 | **eliminato** | — | 0 usi nei componenti |
| `2xl` | *(24, non tarato)* | **27** | 29 | subentra a `title` |
| `3xl` | *(30, non tarato)* | **31** | 33 | riserva per i numeroni del cruscotto (M4.4) |

**Il bottone non si muove**: oggi `text-md` = 13, domani `text-sm` = 13. È il controllo più
veloce che la modifica sia andata come previsto.

**Le interlinee non si toccano.** In Tailwind v4 ogni gradino porta una
`--text-*--line-height` espressa come **rapporto**, quindi segue la misura da sé: a 12px
il `sm` rende 17.14px di interlinea, a 13px renderà 18.57. Non c'è niente da riallineare, e
chi provasse a «sistemarle» romperebbe la proporzione.
**Una eccezione da guardare**: `title` non aveva una `--text-title--line-height`, quindi
ereditava 1.5; `2xl` ha quella di Tailwind, 1.333. Il titolo di pagina cambierà interlinea
oltre che corpo. È atteso — va solo guardato che stia bene.

## 2. Le tre modifiche, in quest'ordine

### 2.1 La costante — `scripts/hex-to-oklch.ts:540`

Oggi la tupla è `[nome, normale, touch, nota]` e i valori touch sono **scritti a mano**,
mentre il commento due righe sopra dichiara che sono `×1.08` arrotondato. Oggi coincidono
tutti e sette, ma sono due fonti per un dato solo. **Vanno derivati**, così la regola
dichiarata e i valori emessi non possono più divergere.

Forma finale della costante — la tupla diventa `[nome, normale, nota]`:

```ts
const TIPOGRAFIA = [
  ["xs", "12px", "micro-etichette, etichette di gruppo della sidebar"],
  ["sm", "13px", "il gradino che regge il 69% dell'interfaccia: voci sidebar, breadcrumb, menu, bottoni"],
  ["base", "15px", "corpo standard, input"],
  ["lg", "16px", "titoli card"],
  ["xl", "19px", "titoli sezione"],
  ["2xl", "27px", "titolo di pagina"],
  ["3xl", "31px", "numeroni del cruscotto"],
] as const;

/** La leva della leggibilità: ×1.08 arrotondato al pixel — vedi il commento sopra.
 *  Derivata, non scritta a mano: era l'unico dato del tema con due fonti. */
const inTouch = (px: string) => `${Math.round(parseFloat(px) * 1.08)}px`;
```

Vanno adeguate `emitScala()` e `emitDensita()` (righe ~551 e ~558), che oggi leggono
`v[i - 1]` dalla tupla a quattro elementi.

Poi:

```bash
npm run theme:build
```

Il CSS del tema è **generato**: non si tocca a mano, `check:contrast` fallisce se diverge.

### 2.2 `text-md` → `text-sm`, e `text-title` → `text-2xl`

**Attenzione, e vale più della modifica**: né `text-md` né `text-title` esistono in
Tailwind. Uno dimenticato **non è un errore di compilazione** — è un'utility sconosciuta
che non emette niente, e il testo eredita la misura del genitore. Muto. Vanno quindi
trovati **tutti**, col `grep` e non con gli occhi:

```bash
grep -rn "text-md\|text-title" registry stories src docs .storybook *.md | grep -v "^registry/.upstream"
```

Al 2026-09-10: **12 occorrenze di `text-md`** — 2 nei componenti (`registry/tassullo/ui/button.tsx`
e `button-group.tsx`), 8 fra story e style guide (titoletti di sezione
`<h3 class="text-md font-semibold">`), 1 in `src/App.tsx`, più il tema — e **`text-title`**
in `stories/Palette.stories.tsx` e in `registry/tassullo/ui/chart.stories.tsx` (l'etichetta
dentro la ciambella).

Sui due componenti **non è un ri-stile in più, è un ri-stile in meno**: tornano
all'originale shadcn su quella stringa, e il conto di `check:registry` scende da 14.

### 2.3 Le pagine che documentano la scala

`stories/Tipografia.stories.tsx`, `stories/Carattere.stories.tsx` e
`stories/Densita.stories.tsx` **elencano i sette gradini uno per uno**, con le note. Se non
si riscrivono, mentono. Va tolta anche la nota «chip, breadcrumb, testi densi» di `md`, che
era **già falsa**: il breadcrumb usa `text-sm`, i chip del combobox pure.

E la riga di `CLAUDE.md` §Regole 5 che descrive la scala.

Lo script va scritto **nella radice del repo**, non nello scratchpad: Node risolve

```bash
cd ../tds-scala && cat > scatti.mts <<'TS'
/** Screenshot di tutte le story, per il confronto prima/dopo di M1.6.
 *  File temporaneo: si cancella prima del commit. */
import { createServer } from "node:http";
import { readFileSync, existsSync, mkdirSync } from "node:fs";
import { join, extname } from "node:path";
import { chromium } from "playwright";

const RADICE = "storybook-static";
const USCITA = process.argv[2] ?? "scatti";
const MIME: Record<string, string> = { ".html":"text/html", ".js":"text/javascript",
  ".css":"text/css", ".json":"application/json", ".svg":"image/svg+xml",
  ".woff2":"font/woff2", ".png":"image/png", ".map":"application/json", ".txt":"text/plain" };

const server = createServer((req, res) => {
  const p = decodeURIComponent((req.url ?? "/").split("?")[0]);
  let f = join(RADICE, p === "/" ? "index.html" : p);
  if (!existsSync(f) || !extname(f)) f = join(RADICE, "index.html");
  try {
    res.writeHead(200, { "content-type": MIME[extname(f)] ?? "application/octet-stream" });
    res.end(readFileSync(f));
  } catch { res.writeHead(404); res.end(); }
});

await new Promise<void>((r) => server.listen(6030, r));
const indice = JSON.parse(readFileSync(join(RADICE, "index.json"), "utf8"));
const storie = Object.values(indice.entries as Record<string, { id: string; type: string }>)
  .filter((e) => e.type === "story").map((e) => e.id);

const browser = await chromium.launch();
for (const densita of ["normale", "touch"]) {
  const dir = join(USCITA, densita);
  mkdirSync(dir, { recursive: true });
  const page = await browser.newPage({ viewport: { width: 1280, height: 800 } });
  for (const id of storie) {

      `http://localhost:6030/iframe.html?id=${id}&viewMode=story&globals=density:${densita}`,

    await page.evaluate(() => document.fonts.ready);
    await page.waitForTimeout(250);
    await page.screenshot({ path: join(dir, id + ".png") });
  }
  await page.close();
  console.log(densita, storie.length, "story");
}
await browser.close(); server.close();
```

## 5. Il gate nuovo — e va provato su un difetto noto

**`check:registry` deve segnalare ogni `text-*` usato nel registry che il tema non tara.**
Poche righe in `scripts/check-registry.ts`: sa già estrarre le stringhe di classi
(`estraiStringhe`) e sa già leggere i token del tema (`tokenDelTema`).

Chiude **due** difetti muti, non uno:

1. un gradino di Tailwind non tarato — oggi `4xl` e oltre — **non scala con la densità**:
   i blocchi `[data-density]` ridichiarano solo i gradini nostri, quindi renderebbe uguale
   nelle due densità senza un avviso;
2. un `text-md` o `text-title` rimasto indietro è un'utility inesistente che non emette
   niente.

**Si prova su un difetto vero prima di dichiararlo funzionante** — è la lezione di M2.9, il
gate che taceva: si infila un `text-4xl` in un componente, si verifica che il gate esca con
codice 1, si toglie.


## 7. Le verifiche

```bash

```

I **cinque** gate. `check:contrast` non c'entra coi corpi ma va verde lo stesso;
`test:a11y` deve restare a **0 violazioni su 868 scansioni**.

**Un avvertimento sull'a11y**: axe usa una soglia di contrasto più bassa per il *testo
grande* — 3:1 invece di 4.5:1, sopra 18.66px in grassetto e 24px in tondo. Ingrandendo il
testo una coppia al limite può **smettere di essere segnalata senza essere stata
aggiustata**. Se una violazione o una *incomplete* sparisce, va capito perché prima di
festeggiare.

`--spacing`, non dal corpo, quindi l'atteso è che si muova poco; le interlinee però contano,
e i campi di testo (`command-input`, `combobox-chip-input`, oggi 18.56px) sono i primi a
muoversi.
